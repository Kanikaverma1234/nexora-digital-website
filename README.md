
# Nexora Digital

Nexora Digital is a responsive digital services company website created as a web development project.

## Pages

- Home
- About Us
- Services
- Portfolio
- Contact

## Services Displayed

- Web Development
- Digital Marketing
- Graphic Design
- SEO Optimization
- Social Media Management
- AI Solutions

## Technologies Used

- HTML5
- CSS3
- Basic JavaScript file structure
- FormSubmit for contact form submissions

## Features

- Responsive website layout
- Navigation between pages
- Portfolio project showcase
- Contact form with required-field validation
- Email inquiry submission through FormSubmit
- Basic SEO meta descriptions
- Mobile-friendly design

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.

## Project Note

The portfolio projects are demonstration concepts created for this assignment.

The contact form uses FormSubmit and requires email activation.
